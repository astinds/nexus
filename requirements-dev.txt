# NEXUS backend dependencies for local development and tests, including the
# Android/Termux environment this repo is developed on.

# Install on Android/Termux (verified working, cp314 / android_24_arm64_v8a):
#   pip install --only-binary=:all: \
#       --extra-index-url https://termux-user-repository.github.io/pypi/ \
#       -r requirements-dev.txt
#   pkg install python-pymupdf libpq        # native bits with no PyPI wheel
#
# Notes for this environment:
#   * --only-binary=:all: is required: source builds fail (no /bin/sh).
#   * The Termux User Repository (TUR) index supplies pydantic-core, lxml, ... .
#   * psycopg[binary] does not exist for bionic: the pure-Python psycopg plus the
#     libpq package is used instead (same driver, same API).
#   * PyMuPDF is only importable when the Termux package loads; see
#     docs/PROJECT_STATE.md ("known environment caveats"). The PdfExtractor
#     automatically falls back to pypdf.
